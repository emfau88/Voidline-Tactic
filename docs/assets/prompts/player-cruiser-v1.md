# Player Cruiser v1 – Generationsspezifikation

Use case: stylized-concept

Asset type: production game sprite for a mobile-first 2D tactics game

Primary request: one original heavy player cruiser, strictly orthographic true top-down view, bow pointing exactly upward

Subject: an abyssal-nautical astronomical warship with a broad armored midsection, a clearly tapered prow, two readable port/starboard cannon terraces, one recessed bow lance aperture, two compact torpedo bays, and three aft engine cavities; strong original silhouette

Style/medium: polished hand-painted 2D game sprite with restrained realistic material rendering; large readable shapes suitable for a 70–110 px mobile display size

Composition/framing: exactly one complete ship centered, vertical orientation, roughly 70 percent of the square canvas, generous transparent padding on every side, no cropping

Lighting/mood: neutral soft top light baked into the sprite; restrained edge highlights; cold, heavy and precise

Color palette: dark graphite and midnight-navy hull plates, narrow cool-cyan gravitational seams, small muted brass accents, pale ivory command spine; no excessive neon

Materials/textures: layered armored metal, subtle wear and panel variation, crisp outer edge, limited microdetail

Constraints: genuinely transparent background with preserved alpha; isolated ship only; visually symmetric enough to rotate cleanly; readable forward direction; original design; no text; no emblem; no logo; no watermark

Avoid: starfield, nebula, floor, shadow plate, glow halo outside the ship, isometric or three-quarter view, perspective distortion, cathedral architecture, skulls, wings, aquila-like symbols, recognizable franchise silhouettes, excessive tiny greebles, photorealistic scene rendering
